## 2. Residual Production Hardening Requirements (Cloud Staging / External Secrets)
- **Cloud KMS / HSM Key Management:** Local Compose/dev uses base64 symmetric key material passed via environment configuration (`AI_SDLC_ENCRYPTION_KEY`); cloud staging/prod should back `EnvelopeCipher` KEKs via AWS KMS / GCP KMS / Vault per `docs/runbooks/backup-restore-and-key-rotation.md`.
- **Multi-Replica Cloud Edge & Live Provider Credentials:** Live PostgreSQL 16 `NOBYPASSRLS` RLS (`ai_sdlc_app`) and Redis-backed `SlidingWindowRateLimiter` are verified in single-host Docker Compose; cloud staging should provision edge WAF rate limits, multi-replica API/worker horizontal scaling soak, and live GitHub App PEM / Stripe / 9Router secrets.
